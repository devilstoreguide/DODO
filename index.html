🔒 MANDATORY SYSTEM PREPARATION

1. Disable Security Software

  • Disable or remove all antivirus software
  • Disable Windows Defender using Defender Controller or manually
    Download Defender Controller
    • After Download, run 'Defender Controller' & Click on Disable.

2. Disable SmartScreen

Download SmartScreen Disabler

  • Download file then run "SmartScreen_OFF.reg" Registry File
  • Agree to the changes in the registry
  • Restart your computer

3. Remove FACEIT Anti-Cheat

Ensure FACEIT Anti-Cheat is completely removed from your system.

Video Tutorial Available: See the video tutorials section below for detailed FACEIT removal guide.

4. Disable Microsoft Vulnerable Driver Blocklist

Download Driver Blocklist Disabler

  • Download file then run "Turn OFF Microsoft Vulnerable Driver Blocklist.reg" Registry File
  • Agree to the changes in the registry
  • Restart your computer
  • If this doesn't help, check that you have removed antivirus and disabled real-time protection

5. Windows Exploit Protection Settings

Windows exploit protection settings (CFG, DEP, ASLR, etc.) must be disabled as shown in the pictures below:

  • Search in Windows settings: Windows Security → Application and browser management → Exploit protection settings

Required Exploit Protection Settings Configuration - System Settings Tab

Critical Settings to Configure:
  • Control flow guard (CFG) → Off by default
  • Data Execution Prevention (DEP) → Use default (On) (Requires restart)
  • Force randomization for images (Mandatory ASLR) → Off by default
  • Randomise memory allocations (Bottom-up ASLR) → Use default (On) (Requires restart)
  • High-entropy ASLR → Use default (On)
  • Validate exception chains (SEHOP) → Off by default
  • Validate heap integrity → Off by default

⚙ BIOS SETTINGS (IMPORTANT)

You must configure these BIOS settings for the product to work correctly:

  • Enable Intel VT-X (Intel CPUs) / Enable AMD-V / SVM Mode (AMD CPUs)
  • Disable Secure Boot

Navigate to BIOS → Search for:

  • Intel Virtualization Technology / VT-X
  • AMD-V / SVM Mode
How to Access BIOS:
  • Restart your computer and press Del, F2, F10, or F12 during boot
  • The exact key depends on your motherboard manufacturer

📌 Recommended PUBG Steam Launch Options

Go to: Steam → Library → PUBG: BATTLEGROUNDS → Right Click → Properties → General → Launch Options

Paste this:

-refresh YOUR_MONITOR_HZ -USEALLAVAILABLECORES -malloc=system -nojoy -novid -nosplash -high -koreanrating

Instead of YOUR_MONITOR_HZ enter your monitor refresh rate like: 100, 120, 144, 165, 240

🎯 Example for 144Hz Monitor:
-refresh 144 -USEALLAVAILABLECORES -malloc=system -nojoy -novid -nosplash -high -koreanrating

PUBG Steam Launch Options Configuration (English Version)

PUBG Steam Launch Options Configuration (Korean Version)

✅ Launch Options Explained:
  • -refresh [HZ] - Sets your monitor refresh rate
  • -USEALLAVAILABLECORES - Utilizes all CPU cores
  • -malloc=system - Uses system memory allocator
  • -nojoy - Disables joystick support
  • -novid - Skips intro videos
  • -nosplash - Skips splash screen
  • -high - Sets game to high priority
  • -koreanrating - Required for Korean rating system

🚀 STARTING INSTRUCTIONS

"Before Run Loader Make Sure Game Mode is Borderless & DirectX11 is Selected in Game."

Note: Your key has expired. You must restart your computer before using a new key to log in!!
  1. 1Run the assistant program as administrator (right-click and select "Administrator").
  2. 2Enter the File Name without '.exe' & Press Enter.
  3. 3Now Enter Folder Path where you saved loader & Press Enter and wait.
  4. 4When Loader asks for Key, paste key and Press Enter.
  5. 5Configure product settings before clicking on 'Inject'.
    • Settings cannot be changed after injection & Menu will not be visible in game.
    • To change settings → close the game and re-inject
  6. 6Now Click on Inject and wait.
  7. 7After a few seconds you get pop-up message box to run game. Click 'OK' and wait for Auto Close Console.
  8. 8After that, if you see more than one loader file, manually delete extras.
  9. 9Start the game.
